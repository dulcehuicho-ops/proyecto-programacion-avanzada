# PROYECTO-PROGRAMACION-AVANZADA---ANALISIS-DE-RESIUDOS
Aplicación web interactiva que permite explorar cuánta basura generan los distritos del Perú entre 2014 y 2024. Usa datos abiertos del Ministerio del Ambiente y presenta, con gráficos y filtros sencillos, cómo evolucionan los residuos en el tiempo, qué departamentos generan más y cómo se relacionan con la población.
